# Model Artifacts

This directory stores trained model weights and metadata.

## Files

| File | Description |
|------|-------------|
| `model_card.md` | Model card with data, metrics, and limitations |
| `policy_sample.pt` | Sample policy weights (PyTorch state dict) |
| `training_metrics.json` | Training run metrics (generated by trainer) |

## Generating Model Weights

```bash
# Run the toy training loop
python -m src.policy.trainer

# Or via make
make train
```

This saves `policy_best.pt` and `training_metrics.json` to this directory.

## Loading a Model

```python
from src.policy.network import PlannerPolicy
import torch

policy = PlannerPolicy(state_dim=32, action_dim=8)
policy.load_state_dict(torch.load("models/policy_sample.pt", weights_only=True))
policy.eval()
```

## Version Control

Large model files (`.pt`, `.bin`, `.onnx`) are in `.gitignore`.
Only the sample weights (`policy_sample.pt`) are tracked for demo purposes.
For production model management, use:
- **MLflow** for experiment tracking
- **DVC** for model versioning
- **S3/GCS** for artifact storage
